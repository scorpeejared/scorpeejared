## Featured Projects

### 🔐 [Wisp](https://github.com/scorpeejared/Wisp)
Private desktop chat built in Rust and Tauri. Messaging uses libsignal (including sealed sender), and the local identity is unlocked with a registered USB drive plus a passphrase. The USB check is device binding, not hardware authentication, so I treat it as one layer of defense. Windows is the tested platform, and it is a personal project that has not been independently audited.
`Rust` `Tauri` `libsignal` `WebSocket` `Docker`

### 🐦 [EarlyBird](https://github.com/scorpeejared/EarlyBird)
Python desktop app that automatically joins your scheduled Google Meet classes. It supports recurring schedules, imports a whole timetable from a screenshot using the AI provider of your choice (Gemini, OpenAI, or any OpenAI-compatible server), and drives your own Chrome, Edge, Brave, or Opera profile.
`Python` `AI / Vision` `Browser Automation`

### 📱 [GovReady (Mobile)](https://github.com/scorpeejared/GovReady)
Android app that tells you exactly which documents to bring before visiting a government office. Pick a transaction, answer a few questions, and get a personalized checklist you can tick off and save. I led the project and handled UX design, QA, and code review.
`Kotlin` `Jetpack Compose` `Material 3` `Navigation Compose`
